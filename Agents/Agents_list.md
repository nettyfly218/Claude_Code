# 常用的 Agents（共 15 个）

## 核心代理

1. **Bash** - 命令执行
   - 用于运行 bash 命令、git 操作、终端命令执行

2. **Explore** - 代码库探索
   - 快速探索代码库，按文件模式查找，搜索代码关键字

3. **general-purpose** - 通用任务
   - 复杂多步推理任务，研究搜索，执行多步骤操作

4. **Plan** - 软件架构设计
   - 设计实现计划，返回分步计划，识别关键文件

5. **claude-code-guide** - Claude Code 使用指南
   - 特性、hooks、MCP 服务器、IDE 集成、快捷键

6. **statusline-setup** - 状态栏配置
   - 配置 Claude Code 状态行设置

7. **codebase-search** - 代码库搜索
   - 搜索文件、代码实现、功能位置

## 代码质量与审查

8. **code-simplifier** - 代码简化
   - 简化和重构代码，提升可读性和可维护性

9. **open-source-librarian** - 开源库管理
   - 理解开源库、查找实现细节、定位源代码

10. **tech-docs-writer** - 技术文档写作
    - 创建和改进技术文档

11. **media-interpreter** - 媒体文件分析
    - 从图片、PDF、媒体文件中提取信息

## 插件开发（plugin-dev）

12. **plugin-dev:agent-creator** - Agent 创建
    - 创建自定义 Agent

13. **plugin-dev:plugin-validator** - 插件验证
    - 验证插件配置

14. **plugin-dev:skill-reviewer** - 技能审查
    - 审查和优化技能

## 对话分析（hookify）

15. **hookify:conversation-analyzer** - 对话分析
    - 分析对话内容，提取关键信息
