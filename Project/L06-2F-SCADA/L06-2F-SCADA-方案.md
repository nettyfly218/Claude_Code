# L06-2F 二流体加湿 SCADA 系统技术方案

## 1. 项目概述

### 1.1 系统目标
为 L06-2F 车间二流体加湿系统建设 SCADA 监控平台，实现：
- 4个加湿区域实时状态监控
- 温湿度数据采集与显示
- 报警管理与实时预警
- 历史数据存储与趋势分析
- 远程参数设定与控制

### 1.2 设备信息

| 项目 | 参数 |
|------|------|
| 设备名称 | L06_H_2F_ELTJS |
| 设备位置 | 西南风柜房 |
| 通讯协议 | Modbus-TCP |
| IP 地址 | 172.169.53.42 |
| 端口 | 502 |
| 设备ID | 1 |
| 采集模块 | EBYTE_NA111 |

## 2. 系统架构

```
│  FUXA SCADA     │ ◄─────────────────────────►│  二流体加湿器   │

```

### 2.2 技术选型

| 组件 | 技术方案 | 说明 |
|------|----------|------|
| SCADA 平台 | FUXA | 开源 HMI/SCADA，支持 Modbus-TCP |
| 数据存储 | SQLite + InfluxDB | FUXA 内置 SQLite，扩展 InfluxDB 用于历史趋势 |
| 通讯驱动 | Modbus TCP | FUXA 原生支持 |
| 前端界面 | FUXA Web Dashboard | 响应式 Web 界面 |
