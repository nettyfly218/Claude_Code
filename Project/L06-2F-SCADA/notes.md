# Notes: L06-2F 二流体加湿 SCADA 系统

## 点表详细信息

### 寄存器地址分布
| 地址范围 | 功能 | 数量 |
|----------|------|------|
| 40001-40004 | 4个区加湿状态 | 4 |
| 40005-40012 | 4个区温湿度 | 8 |
| 40013-40019 | 设备信息+控制方式 | 7 |
| 40020-40027 | 4个区湿度限值设定(读写) | 8 |
| 40028-40031 | 4个区漏水报警 | 4 |
| 40032 | 水路阀门状态 | 1 |
| 40033-40036 | 4个区温湿度计离线报警 | 4 |

### 报警详情 (40014 设备报警状态)
| 值 | 含义 |
|----|------|
| 0 | 正常 |
| 1 | 气路报警 |
| 2 | 水路报警 |
| 3 | 1区漏水 |
| 4 | 2区漏水 |
| 5 | 3区漏水 |
| 6 | 4区漏水 |
| 7 | 屏幕与PLC通讯异常 |
| 8 | 采集模块与屏幕通讯异常 |

### 数据换算
- **湿度**: 寄存器值 × 0.1 = 实际湿度% (范围 0-100%)
- **温度**: 寄存器值 × 0.1 = 实际温度℃ (范围 -10-60℃)

## 监控需求分析

### 必须监控 (Read Only)
1. 4个区的加湿状态 (40001-40004)
2. 4个区的湿度值 (40005,40007,40009,40011)
3. 4个区的温度值 (40006,40008,40010,40012)
4. 设备报警状态 (40014)
5. 远控状态 (40015)
6. 4个区的控制方式 (40016-40019)
7. 4个区的漏水报警 (40028-40031)
8. 水路阀门状态 (40032)
9. 4个区的温湿度计离线报警 (40033-40036)

### 可控制 (Read/Write)
1. 4个区的湿度高限设定 (40020,40022,40024,40026)
2. 4个区的湿度低限设定 (40021,40023,40025,40027)

## 报警分类
| 级别 | 类型 | 来源寄存器 |
|------|------|------------|
| 紧急 | 设备报警 | 40014 |
| 紧急 | 漏水报警 | 40028-40031 |
| 警告 | 温湿度计离线 | 40033-40036 |
